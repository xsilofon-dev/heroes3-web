# ⚔️ Heroes of Might and Magic III - 1:1 Web & Mobile Edition

Автентичний оригінальний порт культової гри **Heroes of Might and Magic III: Complete Edition (1999)** у веб-браузері на базі WebAssembly (WASM).

🌐 **Грати онлайн:** [https://xsilofon-dev.github.io/heroes3-web/](https://xsilofon-dev.github.io/heroes3-web/)

---

## 🎮 Особливості

- **100% оригінальний ПК-рушій:** Автентична графіка 1999 року, оригінальні файли ресурсів (`.lod`, `.snd`, `.vid`), замки, істоти, заклинання та саундтрек Пола Ромеро.
- **Оптимізовано для планшетів та смартфонів:**
  - 👆 **Одиночний тап:** вибір героїв, рух по карті, взаємодія з об'єктами, атака.
  - ⏱️ **Довгий тап (утримання 0.5с):** емуляція правої кнопки миші (ПКМ) для перегляду характеристик істот, споруд та заклинань.
  - ✌️ **Два пальці (Pinch & Pan):** вільне масштабування та огляд карти пригод.
  - ⛶ **Повноекранний режим:** робота без адресного рядка браузера на весь екран планшета.
- **Збереження прогресу:** автоматичне збереження в локальну базу браузера (IndexedDB).
- **Офлайн-режим:** підтримка гри без підключення до мережі (функція «Без інтернету»).
- **Усі офіційні кампанії та сценарії:** «Відродження Ерафії», «Клинок Армагеддону», «Дихання Смерті» та понад 160 карт.

---

## 📱 Встановлення як додаток на планшет (PWA)

1. Відкрийте посилання [https://xsilofon-dev.github.io/heroes3-web/](https://xsilofon-dev.github.io/heroes3-web/) у браузері Chrome / Safari / Firefox на планшеті або телефоні.
2. У меню браузера виберіть **«Додати на головний екран»** (Add to Home Screen).
3. Запускайте як повноцінний окремий додаток без рамок браузера!
